IRLSAFETY+ — Custom overlay images for censorship
===============================================

Use Censor Style = "Custom Image / Pattern" in filter settings.

BUNDLED SAMPLE (release default)
--------------------------------
  sample-censored.png   — [CENSORED] bar with transparency

YOUR OWN OVERLAYS
-----------------
  Filter → Detection & Censor → Custom Overlay Image
  Supported now: PNG, JPG, JPEG, WebP (static)
  Planned: animated GIF, emote packs

Tips:
  - Use PNG with alpha for odd shapes and transparent edges
  - Image stretches to fit each detected region
  - Works on GPU path (Display/Window Capture); cameras use CPU path

Install folder:
  %ProgramFiles%\obs-studio\data\obs-plugins\irlsafety-plus\overlays\
