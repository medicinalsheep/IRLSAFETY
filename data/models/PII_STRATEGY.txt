IRLSAFETY+ — Privacy Strategy (Detection + OCR + Training Roadmap)
====================================================================

MISSION
-------
Eliminate identity leaks on stream: plates, signs, labels, cards, account numbers,
and anything OCR can read — 100% on your PC.

THREE LAYERS (use all three)
----------------------------
1. YOLO detection (irlsafety-detect.onnx)
   - Finds objects before OCR: plates, signs, shipping labels, IDs (when trained)
   - Lightweight YOLOv8n (~12 MB) ships in release packages
   - Train on YOUR frames for your camera angle

2. OCR + Sensitive Patterns (OFF by default in v0.7 — enable in Advanced)
   - Credit cards (Luhn-valid 13–19 digit runs)
   - Shipping tracking (UPS 1Z…, USPS/FedEx long numeric, Amazon TBA…)
   - SSN-style ###-##-####
   - US phone numbers (10–11 digits)
   - Long ID sequences (10+ digits)
   - Filter category: "Sensitive Numbers (cards, tracking, IDs)"

3. Custom PII keywords
   - Names, emails, handles, addresses you add manually
   - Partial match + typing mode for chat overlays

RELEASE MODEL
-------------
  data/models/irlsafety-detect.onnx

  Bundled releases may ship 2-class (plates + signs) until you retrain locally.
  ~12 MB YOLOv8n — DirectML/CUDA on Windows when available.

TRAINING TAXONOMY (v0.7)
--------------------------
  0 = license_plate
  1 = street_sign
  2 = shipping_label   (UPS, FedEx, Amazon, USPS, mail parcels)
  3 = id_document      (driver license, state ID)

  See TRAINING_SESSION.txt for capture checklist.
  Use train-model.ps1 -OBB for angled label coverage (Angled Cover in filter).

OPTIONAL FUTURE CLASSES
-----------------------
  payment_card — OCR + Sensitive Patterns often sufficient today
  face         — optional; not in v0.7 UI

See data/training/classes_roadmap.txt for LabelImg class names.

CAPTURE TIPS FOR NEW CATEGORIES
-------------------------------
  Shipping labels: varied carriers, crumpled labels, thermal print, partial glare
  Cards: edge cases (amex 15-digit, spaced groups, screen reflections)
  ID numbers: order confirmations, account screens, chat digits typed live
  Always capture from YOUR actual stream setup (GoPro, HDMI, display capture)

TUNING IN OBS
-------------
  Sensitive Patterns ON + Screen Text OFF = numbers only (less CPU)
  Sensitive Patterns ON + Screen Text ON = full desktop protection
  OCR Detail = Maximum for small receipt/label text
  Angled Cover ON when using an OBB-trained model for tilted labels

PRIVACY
-------
  No cloud. No telemetry. Training data stays on your disk (or Z:\ RAM disk).
  Pattern matching runs locally on OCR boxes — not full-frame upload.

See TRAINING.txt (how to train), OCR.txt (text engines), PLATFORMS.txt (apps).
