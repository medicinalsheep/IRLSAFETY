IRLSAFETY+ — Train US License Plates & Street Signs (100% local)
================================================================

GOAL
----
Produce:  data/models/irlsafety-detect.onnx
Classes:  0 = license_plate   1 = street_sign   (2 = document, 3 = face optional)

QUICK START (one command)
-------------------------
From the repo OR after install (Control dock -> Train US Model):

  scripts\train-model.ps1

This will:
  1. Install Python deps (ultralytics, onnx, pillow) — local only
  2. Download US bootstrap data if you have few labels:
       - LISA Traffic Signs (UCSD) — typical US road signs
       - HuggingFace license-plate boxes (optional download)
  3. Train YOLOv8n on your PC
  4. Export ONNX and copy to OBS models folder

REQUIREMENTS
------------
  - Python 3.10+ (Add to PATH during install)
  - NVIDIA GPU recommended (CPU works, slower)
  - ~2 GB disk for bootstrap data

STEP BY STEP
------------
1) Setup (once)
     scripts\setup-training.ps1

2) Bootstrap US starter images (recommended first time)
     scripts\fetch-us-bootstrap.ps1

3) Add YOUR stream frames (critical for your camera angle)
     OBS -> Docks -> IRLSAFETY+ Control -> Capture Frame for Training
     Saves to:  %APPDATA%\obs-studio\plugin_config\irlsafety-plus\training\images\train

4) Label boxes (offline, LabelImg)
     scripts\label-images.ps1

     Class names MUST be:
       license_plate
       street_sign

5) Train + export
     scripts\train-model.ps1

6) Test in OBS
     Enable License Plates + Street Signs
     Control dock -> Reload Model
     Debug Logging ON — log should show: Object detection — N region(s)

WHY ADD YOUR OWN FRAMES?
------------------------
Bootstrap data teaches generic US signs/plates. Your GoPro angle, lighting,
and state plate styles need frames from YOUR setup — capture while streaming.

PRIVACY
-------
  - No cloud training. No uploads by this plugin.
  - Bootstrap downloads public research datasets to your disk only.
  - Do not upload stream frames to Roboflow if privacy matters.

TROUBLESHOOTING
---------------
  "Not enough labeled data" -> run fetch-us-bootstrap.ps1, then label-images.ps1
  Model loads but no detections -> add more val frames from your actual stream
  COCO model rejected in log -> you need a CUSTOM trained onnx, not yolov8n COCO

Control dock buttons: Label Images | Train US Model
