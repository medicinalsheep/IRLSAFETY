     cd X:\irlsafety-training-kit

     .\jwcom2-prep.ps1                  # audit counts (mail/ID targets)
     .\jwcom2-label.ps1                 # LabelImg — label staging first if captures waiting
     .\jwcom2-prep.ps1 -Ingest          # move staging → train (after labeling staging)

  C) JWCOM4 — deploy

     Control dock → Reload Model
     Enable Mail & Shipping Labels + IDs & Licenses

TROUBLESHOOTING
---------------
  Cannot reach \\192.168.1.11\R\...  → JWCOM4 on? RAM disk share up?
  -RequireV07 blocks train            → label more mail/ID, re-run prep
  LabelImg missing                    → python -m pip install labelImg
  Captures not on RAM disk            → setx on JWCOM4 + restart OBS
  Training slow over network          → use -RunsLocal on a local folder
