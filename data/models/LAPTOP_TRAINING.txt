IRLSAFETY+ — Local GPU Training
===============================

Train on one Windows PC. Capture in OBS, label, then train.
Nothing uploads to the cloud.

DATASET
-------
  Default:  %APPDATA%\obs-studio\plugin_config\irlsafety-plus\training
  Override: setx IRLSAFETY_TRAINING_ROOT <local-folder>   then restart OBS

  Do not point this at a LAN share unless you intend to. Training
  writes a lot of checkpoint I/O — a local SSD is much faster.


ONE-TIME SETUP
--------------
  1. Install Python 3.10+ from python.org (check "Add python.exe to PATH")
  2. From the repo:
       scripts\setup-training.ps1

  This creates dataset folders, copies classes.txt, and installs
  ultralytics + onnx + labelImg locally.


TRAINING PROPS
--------------
  Rebuild official specimens + 4x6 carrier layouts:
    data\scripts\build-props.ps1

  Print licenses on cardstock; print labels 4x6 and tape to boxes/mailers.
  See data\training\props\PROPS_GUIDE.txt and SOURCES.json.


v0.8 SESSION — FULL WORKFLOW
----------------------------

  A) Capture with printed props
     - Control dock → Capture Frame (→ images/staging)
     - See TRAINING_SESSION.txt for the shot list

  B) Label + train
     scripts\label-images.ps1
     data\scripts\ingest-captures.ps1
     scripts\train-model.ps1 -RequireV07 -WarmStart -SkipBootstrap -Device 0 -Epochs 100

  C) Deploy
     Copy data\models\irlsafety-detect.onnx to the OBS plugin models\ folder
     Control dock → Reload Model
     Enable Mail & Shipping Labels + IDs & Licenses


CLASSES (LabelImg — exact names)
--------------------------------
  license_plate
  street_sign
  shipping_label     ← all carriers (UPS, FedEx, Amazon, USPS, DHL)
  id_document        ← driver license, state ID

  Draw TIGHT boxes on the label or card only.


CURRENT DATASET BASELINE
------------------------
  Plates/signs: 800 train + 200 val (trained — mAP50 ~99%)
  Mail/ID:      add via this session (0 → 50+ / 30+ boxes)
  Warm-start uses the previous best.pt if present under runs\


SCRIPTS
-------
  scripts\setup-training.ps1     One-time Python + folders
  data\scripts\build-props.ps1   Download DMV specimens + build 4x6 labels
  data\scripts\ingest-captures.ps1   Move staging → train
  scripts\label-images.ps1       Open LabelImg
  scripts\train-model.ps1        Train + export ONNX


OPTIONAL FLAGS
--------------
  Faster training runs (local SSD):
    scripts\train-model.ps1 -RequireV07 -WarmStart -SkipBootstrap -Device 0 `
      -RunsLocal C:\temp\irlsafety-runs

  Angled OBB pass (after OBB labels exist):
    scripts\train-model.ps1 -OBB -RequireV07 -WarmStart -SkipBootstrap -Device 0


TROUBLESHOOTING
---------------
  -RequireV07 blocks train     → label more mail/ID, re-run ingest
  LabelImg missing             → python -m pip install labelImg
  Captures not where expected  → check IRLSAFETY_TRAINING_ROOT, restart OBS
  python is the wrong install  → use py -3.12 (or your 3.10+) not Inkscape
  Training slow                → use -RunsLocal on a local SSD; confirm GPU with nvidia-smi
