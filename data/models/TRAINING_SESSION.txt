IRLSAFETY+ — v08 Training Session (single machine, local only)
==============================================================

PLANNED FOR: v0.9.6 bundled model (Windows + Android)
HOST:        one Windows PC (capture in OBS + label + train)
DATASET:     %IRLSAFETY_TRAINING_ROOT%
             or %APPDATA%\obs-studio\plugin_config\irlsafety-plus\training

Nothing uploads to the cloud.


BASELINE (v07 — shipped in Windows 0.9.5 / Android 0.9.6-dev)
--------------------------------------------------------
  4-class irlsafety-detect.onnx bundled in releases
  Classes: license_plate, street_sign, shipping_label, id_document
  Plates/signs: strong (mAP50 ~99% on bootstrap + warm-start)
  Mail/ID: present but needs more real-world variety for v08


NEXT GOAL — irlsafety_v08
-------------------------
  Same 4 classes — improve mail + ID robustness, not new taxonomy

  shipping_label  ≥ 50 boxes (more angles, carriers, partial frames)
  id_document     ≥ 30 boxes (glare, hand-held, desk scenes)
  Hard negatives: plain cardboard, empty desk, no-label packages


WORKFLOW
--------

PHASE 0 — Props
  [ ] From repo: data\scripts\build-props.ps1
  [ ] Print data\training\props\driver_licenses\
  [ ] Print data\training\props\shipping_labels\
  [ ] Tape 4x6 labels to boxes/mailers; cardstock licenses

PHASE A — Capture (OBS on this machine)
  [ ] Optional: setx IRLSAFETY_TRAINING_ROOT <local-folder>
  [ ] Restart OBS if you changed the env var
  [ ] Control dock → Capture Frame (15–25 frames per batch)

  shipping_label:
    [ ] UPS / FedEx / Amazon / USPS / DHL labels
    [ ] 30–45° angle, partial edge crop, hand holding package

  id_document:
    [ ] Flat license, tilted ~30°, glare, in hand, on desk by keyboard

PHASE B — Label
  [ ] scripts\label-images.ps1
  [ ] data\scripts\ingest-captures.ps1   (after labeling staging)

PHASE C — Validate
  [ ] scripts\train-model.ps1 -RequireV07
      (exits if mail/ID counts are below the gate)

PHASE D — Train
  [ ] scripts\train-model.ps1 -RequireV07 -WarmStart -SkipBootstrap -Device 0 -Epochs 100
  [ ] Run name: irlsafety_v08
  [ ] Optional faster runs: -RunsLocal C:\temp\irlsafety-runs

  Phase 2 (after axis-aligned v08 validates):
    [ ] Re-label tilted frames as OBB
    [ ] scripts\train-model.ps1 -OBB -RequireV07 -WarmStart -Device 0

PHASE E — Deploy
  [ ] Copy best.onnx → repo data\models\irlsafety-detect.onnx
  [ ] Copy to OBS plugin models\ → Reload Model
  [ ] Test all four categories + Angled Cover ON
  [ ] Rebuild Windows package + Android APK for v0.9.6 release
