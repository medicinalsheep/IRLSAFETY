IRLSAFETY+ — Samsung Galaxy (Android app)
==========================================

Applies to: IRLSAFETY+ Android 0.9.6-dev (pre-1.0)
Primary test targets: Galaxy A53/A54/A55 (mid-range), Galaxy S21–S24 series, Galaxy Z Fold/Flip

REFERENCE DEVICE (medicinalsheep)
---------------------------------
Galaxy A53 · One UI 8.0 · Android 16
  - Exynos 1280 SoC (most regions) — expect NNAPI or XNNPACK/CPU EP
  - Ideal mid-range alpha tester; matches MVP performance targets
  - If preview stutters: Battery → Unrestricted, frame_skip 8–10 (P14 settings)

STATUS
------
P12 ships ONNX Runtime + irlsafety-detect.onnx on-device. Samsung-specific
tuning matters because One UI aggressively manages background CPU/GPU and
NNAPI behavior differs between Exynos and Snapdragon variants.

BEFORE YOU TEST
---------------
1. Build/install 0.9.6-dev APK (scripts\package-android-apk.bat or android/README.txt)
2. Grant Camera permission when prompted
3. Open logcat filter: IRLSAFETY+
4. Expect "detector=ready" and EP=NNAPI (Snapdragon) or CPU/XNNPACK (Exynos)

ONE UI BATTERY & BACKGROUND
---------------------------
Samsung may throttle the app if battery optimization is ON:

  Settings → Apps → IRLSAFETY+ → Battery
    → Unrestricted (recommended for live camera testing)

  Settings → Battery and device care → Background usage limits
    → Remove IRLSAFETY+ from Sleeping/Deep sleeping apps if preview stalls

If preview freezes after locking the screen, that is expected v1 behavior —
keep the screen on during IRL testing.

THERMAL THROTTLING
------------------
Galaxy devices reduce CPU/GPU clocks when skin temperature rises.
IRLSAFETY+ defaults to frame_skip=6 (~5 Hz detection @ 30 fps preview).

If you see stutter or rising inference latency:

  - Let the phone cool between sessions
  - Disable unused detection categories (P14 settings)
  - Increase frame skip in settings when available (try 10–15)
  - Close Game Launcher / performance overlays competing for GPU

EXYNOS vs SNAPDRAGON
--------------------
Many Galaxy models ship two SoC variants (especially EU vs US).

| SoC family        | ORT EP (P12 plan)     | Notes |
|-------------------|-----------------------|-------|
| Snapdragon 8 Gen  | NNAPI + GPU delegate  | Best NNAPI path; test first |
| Exynos 2100/2200  | NNAPI, XNNPACK fallback | Some ops fall back to CPU — watch logcat EP line |
| Mid-range Exynos  | XNNPACK CPU default   | May need frame_skip 10+ for smooth preview |

Logcat status line shows active EP after P12:
  frames=N · overlays=N · detector=ready · EP=NNAPI · skip=6

If EP shows CPU on a flagship, try:
  - Samsung "Performance mode" (Game Booster / Labs) during test only
  - Reinstall after a full reboot (clears stuck NNAPI cache on some builds)

CAMERAX ON SAMSUNG
------------------
CameraX is the default capture path — it handles Samsung HAL quirks better
than raw Camera2 for MVP.

Known behaviors:
  - YUV_420_888 plane strides vary by resolution — JNI bridge handles per-plane stride
  - Ultra-wide vs main lens: v1 binds DEFAULT_BACK_CAMERA (main lens)
  - 1080p analysis is typical; 4K analysis not targeted for v1

If preview is black:
  - Confirm another app is not holding the camera
  - Force-stop Camera, then relaunch IRLSAFETY+
  - Toggle permission off/on in App permissions → Camera

GALAXY-SPECIFIC FEATURES (out of v1 scope)
------------------------------------------
  - Secure Folder separate install — not supported in alpha
  - Samsung DeX desktop mode — untested
  - Bixby Vision / object detection — unrelated; IRLSAFETY runs locally
