I have a key

  1. Save the one-line key to a file (example: my-pro.key).
  2. Run as admin if needed: 
    powershell -ExecutionPolicy Bypass -File scripts\install-pro-license.ps1 -KeyFile path\to\my-pro.key
  3. Confirm: 
    powershell -ExecutionPolicy Bypass -File scripts\verify-pro-features.ps1
  4. Apply Studio defaults from pro/presets/APPLY_STUDIO.txt (or set plates, mail, IDs, signs ON and Screen Text OFF in the OBS filter).

License path: %ProgramData%\IRLSAFETY+\license.key

Local-only privacy

Detection and OCR run on-device. A Pro license is an HMAC-signed string you keep locally. Optional model update checks only read a small JSON manifest you choose. Downloads never run silently; checksum verify is required.
