IRLSAFETY+ v0.0.0 — Windows Test Package
========================================

QUICK INSTALL (OBS already installed)
------------------------------------
1. Double-click: install-from-package.bat
2. Restart OBS Studio
3. Right-click any video source → Filters → + → "IRLSAFETY+ PII Blur"

QUICK TEST IN OBS
-----------------
1. Enable "Enable All Protection" (on by default)
2. Toggle categories: Street Signs, License Plates, Documents, Faces, Screen Text, Custom PII
3. Under "Custom PII List":
   - Type names/addresses/usernames (one per line), OR
   - Browse to custom-pii.example.txt (or your own .txt file)
4. Adjust Blur Intensity and "Process Every N Frames" for performance

v0.0.0 NOTES
------------
This is a scaffold release: the filter UI and pipeline are wired, but ONNX/YOLO
inference, OCR, tracking, and real blur are not yet active. Settings are saved
with your OBS scene. Future versions will enable detection without UI changes.

REQUIREMENTS
------------
- Windows 10/11 x64
- OBS Studio 31.x (64-bit)

UNINSTALL
---------
Delete these files:
  %ProgramFiles%\obs-studio\obs-plugins\64bit\irlsafety-plus.dll
  %ProgramFiles%\obs-studio\data\obs-plugins\irlsafety-plus\
