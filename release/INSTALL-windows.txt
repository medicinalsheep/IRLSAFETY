IRLSAFETY+ — Windows install & test
===================================

MIT License — see LICENSE in this package.

Version is printed on the release zip name (IRLSAFETY+-vX.Y.Z-win64).
See buildspec.json / GitHub Releases for the current build.

TARGET HARDWARE (defaults tuned for this)
-----------------------------------------
- 4–6 GB VRAM GPUs (GTX 1650 / 1060 6GB, RX 580 class) or modest iGPU + CPU
- 16 GB system RAM recommended; 8 GB workable with defaults below
- OBS canvas 1080p30 or 720p60 — avoid 1440p60 + heavy browser sources on first test

Fresh installs default to **Scan every 8 frames**, **Screen Text OFF**, **Prefer GPU ON**
(DirectML). That keeps YOLO at ~3–4 runs/sec at 30 fps without starving OBS.

KNOWN LIMITS (honest expectations)
----------------------------------
- Detection is best-effort. Missed mail labels / IDs / plates can still leak.
- v07 model is strongest on US plates and street signs; shipping labels and IDs
  improve with the next local training pass (irlsafety_v08).
- Printed training props ≠ crumpled real packages under glare — retrain on your
  setup for best results (see data/models/TRAINING_SESSION.txt).
- Screen Text / Custom PII OCR is OFF by default (heavier path).

REQUIREMENTS
------------
- Windows 10/11 x64
- OBS Studio 31.x or 32.x (64-bit)
- Windows OCR language pack (only if you enable Screen Text or Custom PII OCR)

BUNDLED MODELS (this package)
-----------------------------
  data\obs-plugins\irlsafety-plus\models\irlsafety-detect.onnx   (~12 MB, 4-class YOLOv8n)
  data\obs-plugins\irlsafety-plus\models\irlsafety-ocr-det.onnx  (child OCR, optional)
  data\obs-plugins\irlsafety-plus\models\irlsafety-ocr-rec.onnx (child OCR, optional)

Classes in irlsafety-detect.onnx:
  0 = license_plate
  1 = street_sign
  2 = shipping_label
  3 = id_document

INSTALL
-------
1. Close OBS completely.
2. Right-click install-from-package.bat → Run as administrator.
3. Restart OBS.
4. Add filter: right-click source → Filters → + → IRLSAFETY+ PII Blur.
5. Keep IRLSAFETY+ at the TOP of the Filters list.
6. Existing filters keep old settings — remove and re-add the filter to pick up
   current defaults (frame skip 8, categories).

VERIFY MODEL IS LOADED
----------------------
1. Open the IRLSAFETY+ tray panel (system tray icon).
2. Select your filter in the dropdown.
3. Enable at least one detection category (License Plates or Street Signs).
4. Click Reload Model.
5. The status line should show something like:
     YOLO 42.3 ms · DML · ~22 scans/min · 0 censored · load Medium
   If you see "YOLO on disk — enable plates/signs + Reload Model", the file
   is installed but inference is not active yet — enable categories and Reload.

6. Optional: Help → Log Files — search for "Object detection" or "YOLO".

IF YOU STILL DROP FRAMES (4–6 GB VRAM / older CPU)
--------------------------------------------------
Start here (in order):
- Frame Skip: **10–12** for webcam, **8–10** for display capture
- Disable categories you do not need (each class adds YOLO work)
- Keep **Screen Text OFF** unless you need on-screen OCR
- Custom PII keywords only when needed (triggers OCR passes)
- OCR Detail: **Standard** (not Maximum)
- OBS: output **30 fps**, canvas **1080p** or **720p**
- Advanced → Prefer GPU: **ON** (DirectML). If DML errors, try OFF for CPU-only YOLO
- Close extra browser/game captures on the same GPU

High-end tuning (8+ GB VRAM): Frame Skip **4–6**, enable Screen Text if needed.

QUICK TEST — red box (no OCR)
-----------------------------
1. Enable All Protection = ON, Test Effect = ON
2. Censor Style = Solid Box, Color = red
3. One red box should appear in the center.

QUICK TEST — Screen Text (OCR)
------------------------------
1. Test Effect = OFF, Screen Text = ON
2. Type HELLO WORLD in large Notepad on the captured monitor
3. Enable Debug Logging (Advanced) and check Help → Log Files for OCR hits.

QUICK TEST — props (detection)
------------------------------
1. Hold a shipping label or ID prop in front of the camera / display
2. Black boxes should appear over the object when confidence is met
3. If nothing appears: lower confidence slightly, Reload Model, check category toggles
